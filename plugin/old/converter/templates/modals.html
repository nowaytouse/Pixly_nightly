❓ Help

🚀 Quick Start

  1. Select images/videos to convert in Eagle
  2. Select conversion mode (Smart/Manual/Video)
  3. Adjust quality parameters (optional)
  4. Click "Start Conversion"

🤖 Smart Mode

Use AI to predict optimal parameters, automatically select format and optimization strategy

  • Size Priority: Minimum file size
  • Balanced Mode: Quality and size balanced (recommended)
  • Quality Priority: Highest quality

⚙️ Manual Mode

Full control over conversion parameters, supports JXL, AVIF, HEIC formats. Mathematical lossless compression guarantees full reversibility.

🎬 Video Processing

Professional manual video encoding, exposes complete low-level parameters (GOP, B-frames, motion estimation, etc.), supports animation to video.

⚡ Quick Conversion

One-click quick conversion:

  • ✨ One-click JPEG to JXL optimization (recommended): Use lossless transcoding to convert all JPEG images to JXL (lossless_jpeg=1), achieving perfect quality and 20-30% size reduction. Only shown when JPEG files are selected.
  • All→AVIF: Batch convert to AVIF format

💡 Tips

  • All conversions automatically preserve metadata (EXIF, XMP, ICC)
  • Supports GPU acceleration (auto-detected)
  • Log window only shows warnings and errors
  • 💎 Mathematical lossless = 100% reversible, no quality loss
  • 🎯 Scope Filtering:Eagle has powerful search and filter features. Recommend filtering files directly in Eagle (supports format, size, resolution, tags, etc.), then use this plugin for conversion. This approach is more flexible and precise than in-plugin filtering.

🔄 AI Function Execution Order

  1. Step 1: 🎨 Smart Format Selection - Recommend optimal format
  2. Step 2: 🧠 AI Parameter Prediction - Predict optimal parameters (quality, distance, speed, etc.)

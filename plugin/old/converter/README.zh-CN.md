# 🎨 PIXLY 转换插件 - Eagle专用

[![版本](https://img.shields.io/badge/版本-4.3.0-blue.svg)](https://eagle.cool/)

- **动态GIF → 视频** - 转换为H.264/H.265
- **视频格式转换** - H.264、H.265、AV1

- **XMP合并** - 合并XMP边车文件

## 📦 安装

### 方式1：Eagle插件商店（推荐）
1. 打开Eagle
2. 前往 **偏好设置** → **插件**
3. 搜索"PIXLY 转换器"
4. 点击 **安装**

### 方式2：手动安装
1. 从 [Releases](https://github.com/yourusername/plxy-easy2jxlavif/releases) 下载最新版本
2. 解压到Eagle插件文件夹：
   - macOS: `~/Library/Application Support/Eagle/plugins/`
   - Windows: `%APPDATA%/Eagle/plugins/`
3. 重启Eagle

### 方式3：开发安装
```bash
# 克隆仓库
git clone https://github.com/yourusername/plxy-easy2jxlavif.git

# 链接插件文件夹
ln -s /path/to/plxy-easy2jxlavif/plugin_v3 ~/Library/Application\ Support/Eagle/plugins/pixly-converter

# 重启Eagle
```

## 🚀 快速开始

### 基础使用

1. 在Eagle资料库中**选择图像**
2. **右键** → 插件 → **PIXLY 转换器**
3. **选择模式**：
   - **智能模式** - 让AI选择最优设置
   - **手动模式** - 完全控制所有参数
4. **配置设置**（质量、格式等）
5. 点击 **开始转换** ▶️

### 智能模式示例
1. 选择PNG图像
2. 打开PIXLY转换器
3. 点击"智能转换"标签
4. 启用"AI质量预测" ✓
5. 启用"格式智能选择" ✓
6. 点击"开始转换"
7. AI自动：
   - 分析图像特征
   - 推荐JXL格式
   - 预测quality=92, effort=7
   - 使用SSIM≥0.95验证

### 手动模式示例
1. 选择JPEG图像
2. 打开PIXLY转换器
3. 点击"手动转换"标签
4. 选择"AVIF"格式
5. 设置质量为85
6. 设置速度为6
7. 点击"开始转换"

## ⚙️ 配置说明

### AI选项（智能模式）

#### 质量预测
- **启用**：AI预测最优质量参数
- **范围**：1-100
- **依据**：图像复杂度、细节级别、噪声

#### 自动优化
- **启用**：自动调整参数获得最佳压缩
- **方法**：贝叶斯优化、PPO学习
- **目标**：在保持质量的同时最小化文件大小

#### SSIM验证
- **启用**：验证输出质量≥95%相似度
- **阈值**：0.90-0.99（默认：0.95）
- **回退**：验证失败时自动使用更高质量重试

#### 格式推荐
- **启用**：AI推荐最佳格式
- **考虑因素**：透明度、动画、复杂度、体积
- **覆盖**：可指定首选格式（JXL、AVIF、WebP）

#### 动图转视频
- **启用**：将动态GIF转换为视频（H.264/H.265）
- **优势**：更小体积、更好兼容性
- **自动**：仅当视频格式更小时转换

### 手动选项

#### 格式选择
- JXL、AVIF、WebP、HEIC、PNG、JPEG

#### 质量（1-100）
- **1-60**：体积优先
- **60-80**：平衡模式
- **80-95**：质量优先
- **95-100**：无损或接近无损

#### 努力值/速度
- **低（1-3）**：快速转换
- **中（4-6）**：平衡
- **高（7-9）**：最佳压缩（较慢）

#### 高级选项
- **无损**：启用无损压缩（JXL、WebP、PNG）
- **距离**：JXL质量距离（0.0-15.0）
- **工作线程**：并行转换线程数（1-16）

## 🐛 故障排除

### 插件未在Eagle中显示
- 验证插件文件夹位置
- 检查Eagle版本（需要v3.0+）
- 完全重启Eagle

### "AI Service not available"
- 确保AI服务正在运行：`ai-service`
- 检查端口3333可访问
- 尝试手动模式（无需AI服务也能工作）

### "Rust service not available"
- 确保Rust服务正在运行：`rust-service`
- 检查端口8080可访问
- 安装所需的CLI工具

### 转换失败
- **检查CLI工具**：`cjxl`、`avifenc`、`cwebp`
- **查看日志**：Eagle → 偏好设置 → 插件 → PIXLY → 日志
- **调试模式**：在插件设置中启用

### 质量不佳
- 提高质量设置（推荐80+）
- 启用SSIM验证
- 尝试不同格式（质量：JXL > AVIF > WebP）

## 💡 提示与最佳实践

### 何时使用智能模式
- ✅ 批量处理大量图片
- ✅ 不熟悉转换参数
- ✅ 希望AI推荐格式
- ✅ 需要质量验证

### 何时使用手动模式
- ✅ 特定质量要求
- ✅ 测试不同设置
- ✅ AI服务不可用
- ✅ 偏好完全控制

### 格式选择指南
- **JXL**：最适合高质量照片，支持透明度
- **AVIF**：压缩率出色，浏览器支持广泛
- **WebP**：良好平衡，通用兼容性
- **HEIC**：Apple生态优化
- **PNG**：需要无损
- **JPEG**：传统兼容性

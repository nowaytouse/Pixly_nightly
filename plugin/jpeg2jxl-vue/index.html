📖使用说明
📷 JPEG
使用 --lossless_jpeg=1 可逆转码，DCT 系数完整保留。
✅ 无论文件大小，始终转换
✅ 可完美还原为原始 JPEG
🖼️ PNG / BMP / TIFF / TGA
使用 -d 0 数学无损压缩。
⚠️ 仅当文件 ≥ 阈值时转换
💡 小文件压缩收益有限，建议保持原格式
⚙️ 阈值设置
默认 1.25 MB，可自定义。
设为 0 关闭过滤，转换所有文件。
建议：大图 ≥1MB 转换效果最佳
💡 提示：JXL 对大文件压缩效果更好，小文件可能反而变大（会自动回退）

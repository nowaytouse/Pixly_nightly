📦 INSTALLATION
═══════════════════════════════════════════════════════════════════════════
  1. Validate plugin:
     $ ./validate.sh
  
  2. Setup binaries (if needed):
     $ ./setup.sh
  
  3. Import to Eagle:
     Eagle → Plugins → Developer → Import Local Plugin → Select this folder

🚀 USAGE
═══════════════════════════════════════════════════════════════════════════
  1. Select JPEG files in Eagle
  2. Open: Plugins → "JPEG to JXL Converter"
  3. Click "Convert to JXL" button
  4. Done! JXL files saved next to originals

🎯 CORE FUNCTIONALITY
═══════════════════════════════════════════════════════════════════════════
  Input:  .jpg, .jpeg, .jpe, .jfif
  Output: .jxl (lossless, -d 0)
  Size:   Typically 20-50% smaller than JPEG
  
💡 TIPS
═══════════════════════════════════════════════════════════════════════════
  • Run ./validate.sh before first use
  • Enable devTools in manifest.json for debugging
  • Check console logs (F12) if conversion fails
  • JXL files can be viewed in Chrome, Edge, Safari (with support)

# 🧪 插件测试指南

## 快速测试步骤

### 1. 重新加载插件
```bash
# 在Eagle中
1. 插件 → 开发者 → 卸载插件
2. 插件 → 开发者 → 加载插件文件夹
3. 选择 plugin/ai/ 或 plugin/format/
```

### 2. 测试窗口宽度
**预期结果**：
- AI插件：窗口宽度 1400px，高度 900px
- Format插件：窗口宽度 1600px，高度 1000px
- 左右两列各占50%，一屏可见所有内容

**如何验证**：
1. 打开插件
2. 观察窗口是否足够宽
3. 检查左右两列是否并排显示

### 3. 测试文件检测
**预期结果**：
- 在Eagle中选择文件后，插件自动加载
- 文件列表显示所有选中的文件
- 文件数量正确显示

**如何验证**：
1. 在Eagle中选择一些图片（JPG/PNG/GIF等）
2. 打开插件
3. 检查右侧文件列表是否显示文件
4. 检查文件数量是否正确

### 4. 测试手动刷新
**预期结果**：
- 点击刷新按钮（🔄）后，重新加载文件列表
- 按钮有旋转动画

**如何验证**：
1. 打开插件
2. 点击右上角的刷新按钮（🔄）
3. 观察文件列表是否更新

### 5. 查看控制台日志
**预期结果**：
- 详细的日志输出
- 可以看到文件加载过程

**如何查看**：
1. 在插件窗口中按 `Cmd+Option+I` (macOS) 或 `Ctrl+Shift+I` (Windows)
2. 切换到 Console 标签
3. 查看日志输出

**预期日志**：

## 常见问题排查

### 问题1：窗口仍然太窄
**可能原因**：
- manifest.json未正确修改
- 插件未重新加载

**解决方案**：
1. 检查manifest.json中的width和height
2. 在Eagle中卸载插件
3. 重新导入插件文件夹

### 问题2：文件列表为空
**可能原因**：
- Eagle API不可用
- 文件格式不支持
- 延迟时间不足

**解决方案**：
1. 打开控制台查看错误
2. 确认Eagle版本支持插件API
3. 点击刷新按钮（🔄）手动刷新
4. 检查文件格式是否支持

### 问题3：刷新按钮不工作
**可能原因**：
- JavaScript未正确加载
- 函数未暴露到全局

**解决方案**：
1. 打开控制台查看错误
2. 检查 `window.loadFilesFromEagle` 是否存在
3. 重新加载插件

### 问题4：控制台无日志
**可能原因**：
- 控制台未打开
- 日志级别设置过高

**解决方案**：
1. 按 `Cmd+Option+I` 打开控制台
2. 确认Console标签已选中
3. 刷新插件

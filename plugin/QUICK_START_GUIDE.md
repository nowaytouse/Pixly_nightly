# 🚀 PIXLY 插件快速启动指南

## 📦 两个插件

### 1. PIXLY AI - 智能多媒体处理
**路径**: `plugin/ai/`  
**适合**: 普通用户，追求便捷和自动化  
**特点**: 最简化界面，AI驱动，一键转换

### 2. PIXLY Format - 专业格式转换
**路径**: `plugin/format/`  
**适合**: 专业用户，需要精细控制  
**特点**: 最丰富参数，专业级控制

---

## 🔧 安装步骤

### 方法1：在Eagle中导入
1. 打开 Eagle
2. 点击 `插件` → `开发者` → `加载插件文件夹`
3. 选择 `plugin/ai/` 或 `plugin/format/`
4. 插件自动加载

### 方法2：复制到Eagle插件目录
```bash
# macOS
cp -r plugin/ai ~/Library/Application\ Support/Eagle/plugins/
cp -r plugin/format ~/Library/Application\ Support/Eagle/plugins/

# Windows
xcopy plugin\ai %APPDATA%\Eagle\plugins\ai\ /E /I
xcopy plugin\format %APPDATA%\Eagle\plugins\format\ /E /I
```

## 🎯 使用流程

### AI插件（3步完成）
1. **在Eagle中选择文件**
   - 支持：图片（JPG/PNG/GIF/WebP/AVIF/JXL/HEIC）
   - 支持：视频（MP4/MOV/AVI/MKV/WebM）

2. **打开PIXLY AI插件**
   - 自动加载选中的文件
   - 选择优化目标：平衡/质量优先/体积优先
   - 勾选需要的AI功能

3. **点击"开始智能转换"**
   - AI自动分析并转换
   - 查看进度和结果
   - 打开输出文件夹

### Format插件（专业控制）
1. **在Eagle中选择文件**
   - 切换转换类型：📷 图像 或 🎬 视频

2. **打开PIXLY Format插件**
   - 自动加载选中的文件
   - 左侧：设置所有参数
   - 右侧：查看文件列表

3. **精确设置参数**
   - 选择输出格式（JXL/AVIF/WebP/HEIC）
   - 调整质量设置
   - 配置格式专属参数
   - 视频：选择容器、编码器、质量控制

4. **点击"开始转换"**
   - 按照设置的参数转换
   - 查看进度和结果
   - 打开输出文件夹

## 💡 使用技巧

### AI插件技巧
1. **平衡模式**：日常使用推荐，质量和体积兼顾
2. **质量优先**：重要照片，追求最佳画质
3. **体积优先**：网络传输，需要最小文件
4. **智能质量预测**：让AI自动选择最佳质量参数
5. **SSIM验证**：确保转换后画质不损失

### Format插件技巧
1. **JXL格式**：
   - JPEG文件：启用"JPEG无损转码"，体积减小10-20%
   - PNG文件：使用Modular模式，适合插画和文字
   - 高质量：Effort=7-9，Distance=0-1.0

2. **AVIF格式**：
   - 照片：Speed=4-6，平衡质量和速度
   - 动画：使用Tiles分块，提升编码速度
   - 高质量：Min Quantizer=0，Max Quantizer=20

3. **WebP格式**：
   - 快速：Method=0-2
   - 平衡：Method=3-4
   - 最佳：Method=5-6

4. **视频转换**：
   - H.265：最佳压缩率，推荐日常使用
   - AV1：次世代编码，文件更小
   - ProRes：专业后期，无损质量
   - CRF=23：高质量推荐值
   - CRF=18：视觉无损

## 🔍 常见问题

### Q1: 转换后文件在哪里？
**A**: 默认输出到原文件所在目录的 `pixly_output` 文件夹

### Q2: 支持哪些格式？
**A**: 
- 图像：JPG/PNG/GIF/WebP/AVIF/JXL/HEIC/HEIF/BMP/TIFF
- 视频：MP4/MOV/AVI/MKV/WebM

### Q3: AI插件和Format插件有什么区别？
**A**:
- **AI插件**：简化界面，AI自动决策，适合普通用户
- **Format插件**：丰富参数，完全控制，适合专业用户

### Q4: 可以同时安装两个插件吗？
**A**: 可以！两个插件完全独立，互不干扰

### Q5: 转换失败怎么办？
**A**: 
1. 检查Rust核心是否安装
2. 查看控制台错误信息
3. 确认文件格式是否支持
4. 尝试降低质量参数

### Q6: 如何切换语言？
**A**: 点击右上角的语言选择器，支持简中/繁中/英文/日文

### Q7: 如何切换主题？
**A**: 点击右上角的主题切换按钮（🌙/☀️）

## 📚 参数说明

### JXL参数
- **Effort**: 1-9，值越大质量越好但速度越慢
- **Distance**: 0.0-15.0，0.0=无损，值越大压缩越多
- **Modular**: 适合插画和文字
- **Progressive**: 渐进式加载
- **Responsive**: 多分辨率层级

### AVIF参数
- **Speed**: 0-10，值越小质量越好但速度越慢
- **Min/Max Quantizer**: 0-63，控制质量范围
- **Chroma**: 4:2:0（标准）/4:2:2（平衡）/4:4:4（最佳）
- **Tiles**: 分块并行编码，提升大图速度

### 视频参数
- **CRF**: 0-51，0=无损，18=视觉无损，23=高质量，28=平衡
- **GOP**: 关键帧间隔，250=10秒@25fps
- **B帧**: 0-16，越多压缩越好但编码越慢
- **参考帧**: 1-16，越多质量越好但需更多解码资源

## 🚀 性能优化建议

1. **批量转换**：一次选择多个文件，提高效率
2. **GPU加速**：自动检测并启用GPU编码
3. **合理参数**：不要盲目追求最高质量
4. **格式选择**：根据用途选择合适格式
5. **预处理**：在Eagle中先筛选需要转换的文件

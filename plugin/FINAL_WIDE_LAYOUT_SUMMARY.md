```
│  参数设置面板       │  文件列表面板               │
│  • 格式选择        │  • 文件数量                 │
│  • 质量设置        │  • 文件卡片                 │
│  • 高级参数        │  • 文件信息                 │
│                   │                            │
│                   │  🚀 转换按钮（底部）         │
└────────────────────┴────────────────────────────┘
```

### CSS Grid 实现
```css
.main-grid {
    display: grid;
    grid-template-columns: 1fr 1fr;  /* 左右各50% */
    gap: 20px;                        /* 列间距 */
}

/* 响应式：小屏幕自动切换单列 */
@media (max-width: 1200px) {
    .main-grid {
        grid-template-columns: 1fr;
    }
}
```

## 常见问题

### Q1: 文件列表为空
**可能原因**：
1. Eagle中没有选择文件
2. 选择的文件格式不支持
3. Eagle API调用失败

**解决方案**：
1. 确认在Eagle中选择了文件
2. 点击刷新按钮（🔄）
3. 打开控制台查看错误
4. 确认文件格式支持（JPG/PNG/GIF/MP4等）

### Q2: 语言切换无效
**可能原因**：
1. i18n.js未正确加载
2. 翻译键不存在

**解决方案**：
1. 打开控制台查看是否有错误
2. 检查是否有 `[i18n] ✅ i18n模块已加载` 日志
3. 刷新插件重试

### Q3: 刷新按钮不工作
**可能原因**：
1. JavaScript未正确加载
2. 函数未暴露到全局

**解决方案**：
1. 打开控制台查看错误
2. 检查 `window.loadFilesFromEagle` 是否存在
3. 重新加载插件

## 🔧 技术实现

### Rust CLI 参数映射

```bash
# AI 机器学习
--ai                    # 智能参数预测
--optimize-mode         # 优化目标（balanced/quality/size）
--validate-files        # AI 文件验证
--fix-format            # 格式自动修正
--check-quality         # SSIM 质量验证
--no-gpu                # 禁用 GPU（默认启用）
--preprocess            # 智能预处理

# 基础参数
--format                # 输出格式
--quality               # 质量（1-100）
--speed                 # 速度（1-10）
--lossless              # 数学无损
```

### 架构原则遵守

✅ **响亮失败**：错误明确报告
✅ **真实调用**：无 fallback，无模拟

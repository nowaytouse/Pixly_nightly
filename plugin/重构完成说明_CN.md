# PIXLY 插件重构完成说明

## 🎯 重构目标达成

根据您的要求，我已经成功将旧版本 `plugin/old/converter/` 完整拆分为两个全新的独立版本：

### 1️⃣ AI 智能版本 (`plugin/ai/`)
**核心理念**: 最简化 · AI 驱动 · 一键优化

**主要特点**:
- 🤖 **极简界面**: 只保留最核心的功能，隐藏所有复杂参数
- 🧠 **AI 全自动**: 格式推荐、质量预测、参数优化全部由 AI 完成
- ⚡ **一键转换**: 选择文件 → 选择预设 → 开始转换，三步完成
- 📊 **智能推荐**: 实时显示 AI 推荐方案和预期效果
- 🎯 **场景优化**: 针对不同媒体类型自动选择最优策略

**继承的核心 AI 功能**:
- ✅ PPO 强化学习质量预测
- ✅ LightGBM 机器学习模型
- ✅ 贝叶斯参数优化
- ✅ SSIM/VMAF 质量验证
- ✅ 场景检测与分析
- ✅ GPU 自动检测
- ✅ 动图转视频智能推荐

### 2️⃣ Format 专业版本 (`plugin/format/`)
**核心理念**: 完全控制 · 专业调优 · 参数丰富

**主要特点**:
- ⚙️ **专业界面**: 所有参数完全暴露，专业用户完全掌控
- 📦 **格式丰富**: 支持 JXL, AVIF, HEIC, WebP, PNG, JPEG 等多种格式
- 🎬 **编码器全**: H.265, H.266, AV1, VP9 等所有主流编码器
- 🔧 **参数完整**: 每个格式的所有高级参数都可以精确调整
- 📊 **实时提示**: 每个参数都有详细说明和最佳实践建议

**继承的完整参数**:

#### 图像格式参数
- **JXL**: Effort (1-9), Distance (0-15), Modular, Progressive, Responsive, Gaborish, Photon Noise, Decoding Speed, Bit Depth (8/10/12/16), Color Space (sRGB/P3/Adobe/ProPhoto), Patches
- **AVIF**: Speed (0-10), Min/Max Quantizer, Chroma Subsampling (420/422/444), Bit Depth (8/10/12), Tiles, Premultiplied Alpha
- **HEIC**: Quality, Encoder (x265/libheif), Chroma Subsampling, Lossless, Thumbnail Embed

#### 视频编码参数
- **质量控制**: CRF (0-51), Rate Control (CRF/CBR/VBR/ABR), Bitrate
- **编码结构**: GOP Size (1-600), B-frames (0-16), Reference Frames (1-16)
- **运动估计**: ME Range (4-512), Subme (1-10), ME Method (Diamond/Hex/UMH/ESA/TESA)
- **滤波器**: Deblock (Alpha/Beta -6~6)

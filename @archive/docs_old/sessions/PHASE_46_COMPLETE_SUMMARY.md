
**观察到的行为**:
- ✅ 直接curl测试: 200 OK, 正常返回JSON
- ✅ 单次Rust CLI测试: 成功完成转换
- ❌ 批量Rust CLI测试: 500错误
- ⚠️ 错误是间歇性的，不是每次都发生

### 可能原因分析

**假说1: 并发问题**
- Python脚本可能不支持并发调用
- Go服务可能有竞态条件

**假说2: 资源问题**
- Python进程可能占用过多资源
- 临时文件未清理

**假说3: 路径问题**
- 某些图像路径不正确
- 相对路径 vs 绝对路径问题

**假说4: 超时问题**
- 复杂图像处理超时
- 默认超时30秒可能不够

### 已验证的事实

1. ✅ **Python脚本本身能工作**
   ```bash
   python3 tools/predict_params.py ... ← 返回正确JSON
   ```

2. ✅ **AI服务HTTP接口能工作**
   ```bash
   curl http://localhost:50052/api/v1/predict ← 200 OK
   ```

3. ✅ **Rust CLI单次转换能工作**
   ```bash
   pixly-rust convert ... ← 成功完成
   ```

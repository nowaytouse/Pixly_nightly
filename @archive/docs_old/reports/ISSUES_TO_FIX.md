## 核心问题（违反质量宣言）

### 1. ❌ 文件选择错误过滤 - 严重问题
**位置**: `file-handler.js:85-92`
**问题**: 根据转换类型过滤文件，导致：
- 图像模式下过滤掉MP4等视频文件
- 视频模式下过滤掉图像文件
- 用户选中的文件被静默忽略
- 视频文件的XMP资源无法被清理（残留）

**影响**: 
- 用户体验差：选中的文件消失
- 数据残留：XMP文件无法清理
- 违反预期：用户不知道为什么文件被过滤

**根本原因**: 不应该在UI层过滤文件，应该：
1. 显示所有用户选中的文件
2. 对不支持的格式给出明确提示
3. 只在转换时验证格式

**修复方案**:
```javascript
// ❌ 错误做法：静默过滤
const filteredFiles = eagleSelection.filter(item => {
    const ext = (item.ext || '').toLowerCase();
    return supportedExts.includes(ext);
});

// ✅ 正确做法：显示所有文件，标记不支持
const allFiles = eagleSelection.map(item => {
    const ext = (item.ext || '').toLowerCase();
    const isSupported = supportedExts.includes(ext);
    return {
        ...item,
        isSupported,
        warningMessage: !isSupported ? `此格式在${conversionType}模式下不支持` : null
    };
});
```

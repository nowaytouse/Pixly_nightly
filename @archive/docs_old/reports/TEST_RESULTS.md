## 已知问题汇总

### 预览插件问题

**问题: AVIF/JXL 格式图片在预览插件中无法使用 Eagle 原生功能**
- **描述**: AVIF 和 JXL 格式的图片在 preview 插件中无法使用 Eagle 的原生放大缩小功能，以及鼠标侧键切换图片功能
- **具体情况**:
  - 受影响格式: AVIF、JXL
  - 受影响功能:
    - Eagle 原生放大缩小功能（无法使用）
    - 鼠标侧键切换图片功能（无法使用）
  - 影响范围: 所有使用 preview 插件预览的 AVIF 和 JXL 格式图片
- **影响**: 
  - 用户体验下降，无法使用 Eagle 的原生交互功能
  - 预览功能不完整，与 Eagle 原生预览体验不一致
  - 可能影响用户对 AVIF 和 JXL 格式的使用意愿
- **优先级**: 中
- **建议**: 
  - 检查 preview 插件对 AVIF 和 JXL 格式的支持
  - 确保预览插件正确集成 Eagle 的原生功能（放大缩小、鼠标侧键切换）
  - 可能需要更新预览插件的格式支持或事件处理逻辑
  - 验证其他格式（如 WebP、HEIC）是否也存在相同问题

### HEIC 格式转换问题

**问题 1: 透明 GIF 转换为 HEIC 后变为紫色背景**
- **描述**: 透明 GIF 图片转换为 HEIC 格式后，透明背景变为紫色背景
- **具体情况**:
  - 受影响格式: HEIC（目标格式）
  - 受影响文件: 包含透明通道的 GIF 图片
  - 影响范围: 所有包含透明背景的 GIF 文件转换为 HEIC 格式时
- **影响**: 
  - 图片视觉效果严重受损
  - 透明背景丢失，影响图片使用场景
  - 用户可能不知道会发生这种情况
- **优先级**: 高
- **建议**: 
  - 在 UI 中添加警告提示，当用户选择将透明图片转换为 HEIC 时，提醒用户透明背景可能会变为紫色
  - 考虑在转换前检测图片是否包含透明通道，并给出相应提示
  - 建议用户对透明图片使用其他格式（如 WebP、AVIF、JXL）

**问题 2: 动态 GIF 转换为 HEIC 后失去动画效果**
- **描述**: 动态 GIF 图片转换为 HEIC 格式后，失去动画效果，变为静态图片
- **具体情况**:
  - 受影响格式: HEIC（目标格式）
  - 受影响文件: 动态 GIF 图片
  - 影响范围: 所有动态 GIF 文件转换为 HEIC 格式时
  - HEIC 格式本身不支持动画（虽然 HEIC 规范支持动画序列，但实际实现中很少支持）
- **影响**: 
  - 动画效果丢失，影响图片功能
  - 用户可能不知道会发生这种情况
  - 动态图片转换为 HEIC 后无法恢复动画效果
- **优先级**: 高
- **建议**: 
  - 在 UI 中添加警告提示，当用户选择将动态图片转换为 HEIC 时，提醒用户动画效果会丢失
  - 考虑在转换前检测图片是否为动态图片，并给出相应提示
  - 建议用户对动态图片使用其他格式（如 WebP、AVIF、JXL）
  - 在文件选择面板中，当检测到动态图片且目标格式为 HEIC 时，显示明显的警告信息

### 2. 违反质量宣言原则

**真实性原则** ❌:
- 前端UI声称有功能
- 参数被传递到CLI
- 后端完全未实现
- 用户被误导

**反对摆设代码** ❌:
- UI控件存在但无实际功能
- 参数被静默忽略
- 用户以为功能生效

**响亮的错误** ❌:
- CLI不报错未知参数
- 用户无法知道功能未生效
- 静默失败
